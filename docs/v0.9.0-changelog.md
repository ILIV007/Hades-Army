## 🎯 v0.9 Feature Summary

### Section 1 — Real Agent System
- ✅ **Real Builder Agent** (`src/agents/real/builder.ts`) — true AI agent that loads Qwen3-Coder via Model Registry, generates structured patches with reasoning + confidence
- ✅ **Real Reviewer Agent** (`src/agents/real/reviewer.ts`) — true AI agent that loads DeepSeek via Model Registry, returns structured verdicts with issues + recommendation + confidence

- ✅ **Manager Personality** (`src/manager/personality.ts`) — Senior Technical Architect behavior. Challenges weak ideas, identifies risks, asks questions, protects repository quality. Includes `decidePatchFate()` decision logic.

- ✅ **Communication Enforcer** (`src/orchestration/communication-enforcer.ts`) — wraps the v0.8.5 protocol with enforcement guards. Validates sender role, persists to D1 for audit, throws on protocol violations.

- ✅ **Memory Enforcer** (`src/memory/memory-enforcer.ts`) — enforces `.hades/` read/write before/after every workflow. Blocks workflows that skip onboarding. Records failure lessons automatically.

- ✅ **AI Factory Adapter** (`src/integrations/ai-factory-adapter.ts`) — resolves the overlap between AI Factory (v0.8.0) and Model Registry (v0.8.5). Registry = decision, AI Factory = execution only. Includes migration-readiness check.

## 📦 Deployment Instructions

### 1. Install dependencies (with new wrangler v4)
```bash
npm install
```

### 2. Run migrations
```bash
# v0.8.5 (if not already applied)
npm run db:migrate:v085

# v0.9.0
npm run db:migrate:v090
```

### 3. Set secrets
```bash
wrangler secret put TELEGRAM_BOT_TOKEN
wrangler secret put GITHUB_TOKEN
wrangler secret put GOOGLE_AI_API_KEY      # Manager (Gemini 3 Flash)
wrangler secret put OPENROUTER_API_KEY     # Builder (Qwen3-Coder) + Reviewer (DeepSeek)
wrangler secret put ADMIN_API_TOKEN
```

### 4. Validate
```bash
npm run validate
```

### 5. Deploy
```bash
npm run deploy
```

### 6. Run tests
```bash
npm test                    # all tests
npm run test:integration    # integration tests only
```
