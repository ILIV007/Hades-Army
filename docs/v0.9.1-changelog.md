### Priority 2 — Memory Reliability ✅

  - KV → D1 (flush ephemeral records: cost_records, agent_metrics_daily)

## 🚀 Deployment Instructions

### 1. Install dependencies
```bash
npm install
```

### 2. Run all migrations
```bash
npm run db:migrate:all    # runs v0.8.5 + v0.9.0 + v0.9.1 in sequence
```

### 3. Set ALL critical secrets
```bash
wrangler secret put TELEGRAM_BOT_TOKEN
wrangler secret put GITHUB_TOKEN
wrangler secret put GOOGLE_AI_API_KEY
wrangler secret put OPENROUTER_API_KEY
wrangler secret put ADMIN_API_TOKEN
wrangler secret put JWT_SECRET            # NEW — min 32 chars
wrangler secret put ENCRYPTION_KEY        # NEW — min 32 chars
```

Generate strong secrets:
```bash
# JWT_SECRET (32+ chars)
openssl rand -base64 48

# ENCRYPTION_KEY (32+ chars)
openssl rand -base64 48
```

### 4. Validate
```bash
npm run validate
```

### 5. Deploy
```bash
npm run deploy
```

### 6. Verify after deploy
- Send `/health` to the Telegram bot — all 7 components should be ✅
- Send `/menu` — main menu should appear with v0.9.1 layout
- Send `/plan` — should switch to Plan mode
- Send `/repositories` — should show empty list (no repos connected yet)

## 🆘 Troubleshooting

### "process is not defined"
This error should now be **completely gone**. If it reappears, run:
```bash
grep -rnE '\bprocess\.' src/ --include="*.ts" | grep -v "// \| \* "
```
The output should be empty.

### Secrets missing
After deploy, send `/health` to the Telegram bot. If "Secrets" shows ❌, the listed names need to be set via `wrangler secret put <NAME>`.

### D1 tables missing
If "D1 Database" shows ❌ or `/health` reports missing tables:
```bash
npm run db:migrate:all
```

### Worker starts in degraded mode
This is expected if not all critical secrets are set. The Worker still runs, but features depending on missing secrets will fail gracefully.
