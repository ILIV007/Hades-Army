## 🚀 Deployment

### 1. New environment variables / secrets

Add these to `wrangler.toml` `[vars]` or via `wrangler secret put`:

```toml
# In [vars] section (non-secret)
GOOGLE_AI_API_KEY = ""   # for Gemini (Manager)
OPENROUTER_API_KEY = ""  # for Qwen3 / DeepSeek (Builder + Reviewer)
# Cloudflare AI binding (already present as `AI`)
# GITHUB_TOKEN (already present)
# TELEGRAM_BOT_TOKEN (already present)
```

### 2. Run SQL migrations

```bash
wrangler d1 execute hades-db --file=./sql/v0.8.5-additions.sql
```

### 3. Deploy

```bash
npm run build
wrangler deploy
```

### 4. Wire the new Telegram controller (optional)

The new `TelegramController` is **additive** — it does not replace the existing bot. To mount it on the same webhook endpoint, add a one-line import in your webhook route handler:

```ts
import { getTelegramController } from "./telegram";

// Inside the /webhook/telegram route:
const controller = getTelegramController(c.env);
await controller.handleUpdate(await c.req.json());
```

This is the only change needed in existing files (and it's optional — v0.8.5 features also work via the REST API).
